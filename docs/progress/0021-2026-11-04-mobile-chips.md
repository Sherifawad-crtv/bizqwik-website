# 0021 — Ecosystem: swipeable pills on mobile

**Date:** 2026-11-04 · Direction: replace the mobile dropdown with side-scrolling clickable pills, as on desktop.

## What changed
- Removed the mobile `<select>`, progress bar and `n/5` counter. The same chip list now serves every size:
  one swipeable row on phones (snap, hidden scrollbar, bleeds to the screen edge), centred and wrapping from `lg`.
- Tapping a pill scrolls it to the centre of the row. Arrow keys still move between tabs.
- Removed the now-unused `alt-arrow-down` usage (icon stays registered in `Icon.tsx`).

## Verification
- Chromium 390 wide, production build: no page overflow, tapping the 4th pill switches the feature and centres the pill;
  no console errors. `tsc`, `oxlint`, `next build` pass.
