# 0065 Bottom fade above the browser bar on phones (2026-11-26)

On iOS Safari the bottom toolbar is tinted with the page's theme colour (paper), so content ended in a hard edge at the bar while the top status bar shows a soft fade. A fixed 72px strip at the bottom of the viewport (phones only, `lg:hidden`) now fades from transparent to the paper colour, so the page dissolves into the bar the same way the status bar's gradient does. The closing section gets extra bottom padding on phones so the footer text can scroll clear of the fade.
Note: the bar itself is drawn by the browser; this only shapes what is above it. Check on a real iPhone (Safari's bar styling differs between iOS versions).
