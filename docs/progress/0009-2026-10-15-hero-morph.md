# 0009 — Hero: pieces morph from manual-process props into Bizqwik components

**Date:** 2026-10-15 · The "crazy idea": the pieces that organise into the phone start as the
spreadsheets, papers and receipts a gym actually runs on, and morph along the way.

## What changed
- `src/components/hero/Chaos.tsx`: nine manual faces in HTML/CSS (sticky note, polaroid,
  calendar strip, receipt, calculator, ledger, clipboard, punch card, spreadsheet).
- `FounderHome.tsx`: `Piece` is now an outer layout box + `data-order` (Bizqwik face) +
  optional `data-chaos` (manual face). Nav pill and FAB are locked with `shrink-0`.
- `hero-motion.ts`: per piece, flight as before, plus a mid-flight morph: the manual face
  reshapes to the card's measured size and radius, straightens, blurs out; the Bizqwik face
  blurs in. Timing offsets `t0 + 0.16` / `t0 + 0.24`. Chart bars still grow as the chart lands.
- Handwriting font Caveat 600, subset to ASCII (18 KB), `font-hand` (fonts.ts, tokens.css).
- Hero `alt` rewritten; greeting scatter pulled inward (`reach 0.5`) so the sticky note isn't cut.
- Docs: DESIGN-SYSTEM (morph table), DECISIONS D-019.
