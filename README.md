# Bizqwik website

Marketing site for Bizqwik (Next.js, TypeScript, Tailwind v4).

```bash
npm install
npm run dev        # http://localhost:3000  (/foundation = style guide)
npm run build && npm run typecheck && npm run lint
```

Hand-off docs: `docs/progress/` (change log, start at the README), `docs/DESIGN-SYSTEM.md`,
`docs/DECISIONS.md`, `docs/ROADMAP.md`. Tokens live in `src/styles/tokens.css`.
